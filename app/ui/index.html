Access evaluation

GET /discord/channels/{channel_id} — asks Discord whether the bot can view the channel and read its history, and why not when it cannot.

Discord has no “approve access” API. An access request here is an internal record in this service’s own database. Nothing is sent to Discord. It means: we want this channel; re-check every 12 hours until a human server admin grants the bot View Channel + Read Message History. ACCEPTED means our own re-check found the bot really can read it — not that Discord approved anything.

Create an access request

POST /discord/channels/{channel_id}/access-request — if the bot can already read the channel, no request is created.
